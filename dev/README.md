# 文本转二维码扩展

这是一个浏览器扩展，可以将选中的文本转换为二维码，方便扫描。
当您在浏览器中选中一些文本时，点击扩展图标，即可将选中的文本转换为二维码。
换行、空格和制表符分割内容，每个二维码对应一行文本。

# Firefox 安装方法

1. 打开 Firefox 浏览器。
2. 输入地址栏 [about:debugging#/runtime/this-firefox](about:debugging#/runtime/this-firefox) 并按下 Enter 键。
3. 点击“加载临时 Add-on”按钮。
4. 选择 `text2qr-extension/firefox/manifest.json` 文件。

# Chrome 安装方法

1. 打开 Chrome 浏览器。
2. 输入地址栏 [chrome://extensions/](chrome://extensions/) 并按下 Enter 键。
3. 点击“加载扩展程序”按钮。
4. 选择 `text2qr-extension/chrome` 目录。
