
# 文本转二维码（浏览器插件）

> 选中网页中的任意文本，右键一键生成二维码；支持批量文本、自动识别商品编码、日期与重量信息，悬浮窗展示。

---

## ✨ 功能特性

- **右键快速转换**：在任意网页上选中文本，右键点击 `制码`，立即弹出二维码悬浮窗
- **批量支持**：支持多行文本，每行独立生成一个二维码，适合批量条码 / 编码转换
- **智能自动处理**：
  - 自动大写（可关闭）
  - 自动格式化库位码（如 `AABBCCDDEE` → `AA-BB-CC-DD-EE`，支持 9 / 10 位）
- **商品信息识别（内置映射表）**：
  - 针对特定数字编码（如 20 位以上纯数字），自动解析**商品码**、**生产日期**（YY年MM月DD日）和**重量（克）**
  - 内置示例商品映射表，可自行扩展商品库
- **动态染色显示**：解析后的数字串中，商品码、日期、重量分别用黄、绿、蓝高亮，一目了然
- **悬浮窗可调**：支持显示 / 隐藏更多选项（自动大写、自动格式化、显示商品信息），文本框实时编辑，二维码即时刷新
- **可拖拽浮窗**：拖动标题栏可移动位置，关闭后不记忆位置
- **完全离线**：二维码生成库内嵌，无运行时网络请求，保护数据隐私

## 📖 使用方法

1. 在任意网页上，用鼠标选中一段或多段文本（支持分行的多条内容）
2. 右键点击，在上下文菜单中选择 **"制码"**
3. 右侧会弹出悬浮窗，自动为每一行（或每个空格分隔的词）生成对应的二维码
4. 悬浮窗内：
   - 可编辑文本区域，修改或新增内容，二维码实时更新
   - 点击 **"更多"** 可切换自动大写、自动格式化库位码、显示商品信息等选项
   - 鼠标悬停二维码，可查看原始文本
   - 拖动标题栏可移动悬浮窗位置
5. 点击右上角 **"X"** 或按下键盘 **`Esc`** 键关闭悬浮窗

## 🧩 扩展商品映射表

商品映射表位于 `productMap.js`，格式为**三列数组**：

```javascript
window.productMapData = [
    ["6934665082047", "蒙牛冠益乳草莓果粒风味发酵乳250g", "否"],
    ["6959169003091", "香辣鱿鱼350g", ""],
    ["21799", "山东重瓣芍药阳光女孩5枝", ""]
];
```

三列依次为：

| 列 | 含义 |
|---|---|
| 第 1 列 | 商品条码 |
| 第 2 列 | 商品名称（**不要包含空格**，生成时会自动去除） |
| 第 3 列 | 当日鲜标志：`'是'` 或 `'true'` 时参与当日鲜判定，其他值视为否 |

插件会匹配 20 位以上数字串中的商品码部分（由前缀和总长度唯一确定 5 位或 7 位），并在悬浮窗中显示对应的商品名称。

- 注：网页版和插件版共用相同的商品库，**格式完全一致**，直接覆盖即可
- 注：`productMap.js` 可通过 [商品名称库](https://gitee.com/cnwz/xxcs/releases/tag/商品名称库) 下载
- 注：可使用网页版工具的 **"条码转键值"** 模块生成该文件

## ⚙️ 配置选项

悬浮窗工具栏中的 **"更多"** 面板提供三个开关：

| 选项 | 说明 |
|---|---|
| **自动大写** | 将文本转换为大写（默认开启） |
| **自动格式化库位码** | 将连续字母数字按规则插入 `-` 分隔，适用于库位编码（默认开启） |
| **显示商品信息** | 若文本匹配商品映射表或含日期 / 重量信息，则显示额外信息行（默认开启） |

## 🛠️ 技术栈

- Manifest V3
- 原生 JavaScript
- 纯前端 QRCode 生成（内嵌 `qrcode-generator` 库）
- 浏览器扩展 API（`contextMenus`, `scripting`, `tabs`, `notifications`）

## 📁 文件结构

```
├── manifest.json        // 扩展清单（Manifest V3）
├── background.js        // 后台服务（注册右键菜单、注入 content script）
├── content.js           // 页面注入脚本（UI 渲染、二维码生成、文本处理）
├── productMap.js        // 商品映射表（可选）
├── qr-code-16.png       // 图标（16x16）
├── qr-code-48.png       // 图标（48x48）
└── qr-code-128.png      // 图标（128x128）
```
